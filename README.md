# 📱 Mobile Usage Behavior Analysis

## 📌 Overview
This project analyzes mobile usage behavior to identify patterns and trends using spreadsheet tools. The goal is to understand how different users interact with their devices and uncover meaningful insights through data visualization.

---

![Data Visualization](https://img.shields.io/badge/Data%20Visualization-orange?style=flat-square)

---

## 🎯 Objective
- Analyze user behavior based on screen time and usage patterns  
- Identify trends across different age groups  
- Understand the impact of usage on battery consumption  

---

## 🛠️ Tools & Techniques
- Google Sheets / Microsoft Excel  
- Data Cleaning  
- Pivot Tables  
- Data Visualization (Charts & Graphs)

## 📈 Key Insights
- Majority of users fall under moderate to heavy usage categories  
- Younger age groups tend to have higher average screen time  
- Increased screen time leads to higher battery consumption
